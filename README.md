## 关于 Freqtrade

Freqtrade 是一个使用 Python 编写的免费开源加密货币交易机器人。它支持多种主流交易所，可通过 Telegram 或 Web UI 进行控制，并包含回测、绘图、资金管理以及机器学习策略优化等功能。
